##### How to setup FreeOTP Authenticator

###### Configure FreeOTP 

###### OTP Type
  `OTP Type` denotes the algorithm for Hashing.

###### OTP Hash Algorithm
  `OTP Hash Algorithm` denotes the algorithm for Hashing.Default is SHA1, more secure options are SHA256 and SHA512.

###### Number of Digits 
  `Number of Digits` denotes the how many characters is the OTP? Short means more user friendly as it is less the user has to type. More means more security.

###### Look Ahead Window
  `Look Ahead Window` tells how far ahead should the server look just in case the token generator and server are out of time sync or counter sync?

###### Initial Counter
  `Initial Counter` denotes the What is the value of the initial counter to be counted?

###### OTP Token Session
  `OTP Token Session` denotes Time interval in seconds during which the server will match a hash. Each time the interval passes, a new TOTP will be generated by the token generator.
