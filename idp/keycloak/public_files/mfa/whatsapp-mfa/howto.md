##### How to setup Whatsapp Factor

###### Configure Whatsapp Factor

###### Verify Way Options
  `Verify Way` option will provides the way for verification to be carried with Whatsapp.

###### If Verification Way is OTP
  If `OTP` way is selected,then OTP will be sent to your Whatsapp Number            

  In this way, we can configure the following options,
    
  `OTP Verification Expiry Duration` denotes the when the OTP expires.Set the duration like,for days 2d, for hours 2h, for minutes 2m, for secs 2s

  `OTP Length` denotes the how many characters is the OTP? Short means more user friendly as it is less the user has to type. More means more security

###### If Verification Way is PUSH
  If `PUSH` way is selected,then PUSH Notification will be sent to your Whatsapp Number for confirmation

  In this way, we can configure the following options,
    
  `Waiting Duration to Receive Response` denotes the waiting time to accept the notification through whatsapp.Set the duration like,for days 2d, for hours 2h, for minutes 2m, for secs 2s
 
###### If Verification Way is QR
  If `QR` way is selected,then QR will be displayed on the screen to scan.

  In this way, we can configure the following options,
    
  `Waiting Duration to Receive Code` denotes the waiting time to send the code which is scanned through QR.Set the duration like,for days 2d, for hours 2h, for minutes 2m, for secs 2s
