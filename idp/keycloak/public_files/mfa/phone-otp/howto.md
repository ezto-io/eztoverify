##### How to setup Phone OTP Factor

###### Configure Phone OTP Factor

###### OTP Expiry Duration
  `Expiry Duration` denotes the when the OTP expires.Set the duration like,for days 2d, for hours 2h, for minutes 2m, for secs 2s

###### OTP Length
  `OTP Length` denotes the how many characters is the OTP? Short means more user friendly as it is less the user has to type. More means more security.

###### Template of text
  `Template of text` is used to customize the text that can be sent in addition to the generated OTP. For example,Your OTP is {code}.

###### SMS Sender
  `SMS Sender` is used to choose the SMS Sender for sending the verification code through SMS.Please ensure that the selected sender is configured correctly.

#### Note
>**Please note that `{code}` is the variable used to map the OTP in template of text field.**
