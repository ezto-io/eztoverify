###### Number of Digits
  `Number of Digits` denotes the how many characters is the OTP? Short means more user friendly as it is less the user has to type. More means more security.

###### Look Ahead Window
  `Look Ahead Window` tells how far ahead should the server look just in case the token generator and server are out of time sync or counter sync?
