###### Github Configuration Instructions
Users will log in to your app using their GitHub profile using the GitHub social connection. 

###### How to setup Connection

###### Prerequisites 
* Create a GitHub Developer account before you begin. 

###### Create a GitHub project for your app 
Please follow the below steps to complete the setup 

1. To enable GitHub login, you must first complete a series of tasks. 

2. You need to get a `Client ID` and `Client Secret` from GitHub first. The `Redirect URI` is one of the pieces of information you'll need from this page.  

3. You'll need to copy this URI to your clipboard when you register QlikVerify as a client on GitHub.  
 
4. To use GitHub for login, you must first create an application project in GitHub Developer Apps.  

5. To create a new application, click the Register a new application button. Copy the Redirect URI from the QlikVerify and paste it into the GitHub Register a new OAuth application page's Authorization callback URL box.  

6. You will be sent to the application's management page once you have finished this step.  

7. To enter the client ID and secret into the QlikVerify page, you'll need to get them from this GitHub page. Return to QlikVerify and specify what you want.
