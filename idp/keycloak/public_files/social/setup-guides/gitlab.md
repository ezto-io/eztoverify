###### GitLab Configuration Instructions
Users will log in to your app using their GitLab profile using the GitLab social connection. 

###### How to setup Connection

###### Prerequisites 
* Create a GitLab Developer account before you begin. 

###### Create a GitLab project for your app 
Please follow the below steps to complete the setup 

1. To enable GitLab login, you must first complete a series of tasks. 

2. You need to get a `Client ID` and `Client Secret` from GitHub first. 

3. To use GitLab for login, you must first register an application as an OAuth2 authentication service provider in GitLab. 

4. Copy the `Redirect URI` from the QlikVerify page and paste it into the GitLab Add new application page's Redirect URI box. 

5. Click Save application after you're finished registering.  

6. This will take you to GitLab's application management page. From this website, copy the client ID and secret and paste them into QlikVerify. 

7. Return to QlikVerify and input them to complete the task. Save the file.
