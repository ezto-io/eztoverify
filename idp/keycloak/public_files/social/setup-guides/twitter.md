###### Twitter  Configuration Instructions
Users will log in to your app using their Twitter profile using the Twitter social connection. 

###### How to setup Connection

###### Prerequisites 
* Create a Twitter account before you begin.

###### Create a Twitter  project for your app 
Please follow the below steps to complete the setup 

1. To enable Twitter login, you must first complete a series of tasks. 

2. You need to get a `Client ID` and `Client Secret` from Twitter first. The `Redirect URI` is one of the pieces of information you'll need from this page.  

3. You'll need to copy this URI to your clipboard when you register QlikVerify as a client on Twitter.  

4. To use Twitter for login, you must first build an application in Twitter Application Management. 

5. To start a new app, click the Create New App button. This will take you to the page where you may create an application. 

6. Create a name and a description for your project.  

7. The website can be anything, however a localhost URL is not permitted. The Redirect URI from the QlikVerify must be copied into the Callback URL. 

8. You'll be sent to the Details page after clicking Save. 

9. Go to the Keys and Access Tokens tab after that. 

10. Finally, copy the `API Key and secret` from this page and paste them into the QlikVerify Client ID and Client Secret boxes.
