###### BitBucket  Configuration Instructions
Users will log in to your app using their BitBucket profile using the BitBucket social connection. 

###### How to setup Connection

###### Prerequisites 
* Create a BitBucket account before you begin. 

###### Create a BitBucket project for your app 
Please follow the below steps to complete the setup 

1. To enable BitBucket login, you must first complete a series of tasks. 

2. You need to get a `Client ID` and `Client Secret` from BitBucket first.  

3. To use Bitbucket for login, you must first create an OAuth application project on Bitbucket Cloud. 

4. To add a `consumer`, click the Add consumer button. 

5. Copy the `Redirect URI` from the QlikVerify and paste it into the Bitbucket Add OAuth Consumer page's Callback URL box. 

6. To allow your application to view user email, check the Email and Read boxes under Account on the same page. 

7. Click `Save` after you've finished registering.  

8. This will take you to Bitbucket's application administration page. This page will provide you the c`lient ID and secret`, which you may use to add an identity provider in QlikVerify.  

9. Save your work.
