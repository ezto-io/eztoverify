##### How to setup SparkPost

###### Prerequisites 
* You must have an [SparkPost](https://www.sparkpost.com/) account.

###### Configure SparkPost 

1. Log in to your [SparkPost](https://www.sparkpost.com/) account. 

2. After Logged in, Setup a custom domain or use the Sandbox Domain(for testing purposes only).

3. Create a new API in the dashboard.

4. Now, Enter the `API Key`,`From` address from Mandrill dashboard and Copy it in the settings and select your `Region`.

###### Note

>**The value of the `API Key` field can refer a value from an external vault. It will be not stored in our database**  
>**SparkPost's sandbox domain is very limited. For this reason, it is very important to setup a custom domain as soon as possible.**
