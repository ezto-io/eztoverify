##### How to setup Vonage

###### Prerequisites 
* You must have an [Vonage](https://www.vonage.com/) account.

###### Configure Vonage 

1. Log in to your [Vonage](https://www.vonage.com/) account. 

2. After Logged in, Enter the  `API key` and `API secret` from vonage and copy it to the dashboard settings.

3. The `From` address that will be seen on the handset when this message arrives, typically either a valid short-code / long code that can be replied to, or a short text description of the application sending the message (Max 11 chars)
