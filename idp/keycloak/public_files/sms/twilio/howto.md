##### How to setup Twilio

###### Prerequisites 
* You must have an [Twilio](https://www.twilio.com/) account.

###### Configure Twilio 

1. Log in to your [Twilio](https://www.twilio.com/) account. 

2. After Logged in, Setup a sender Number for the project you created in twilio.

3. Once sender Number is successfully configured, then copy the `SenderNumber`, `Account SID` and `Auth Token` into the dashboard settings


###### Note

>**The value of the `Auth Token` field can refer a value from an external vault. It will be not stored in our database.So it can be showed on creating or updating twilio provider.**
