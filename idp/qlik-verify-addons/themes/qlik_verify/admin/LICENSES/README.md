One file per component, copied from its own release at the version the theme ships (see THIRD-PARTY-NOTICES.md for
the overview). Written by the OSS migration harness (scripts/admin/licenses-collect.py). Technical inventory, not
legal advice.

Shared texts: [Apache-2.0.txt](Apache-2.0.txt), [Unicode-License-V3.txt](Unicode-License-V3.txt); address data in
region-helper.js: [region-helper-address-data.txt](region-helper-address-data.txt). Fonts: the SIL OFL 1.1 texts are
next to the fonts (resources/themes/fonts/inter/OFL.txt, open-sans/OFL.txt, Rubik-OFL.txt). Keycloak (Apache-2.0):
idp/keycloak/LICENSE.txt in this repository.
