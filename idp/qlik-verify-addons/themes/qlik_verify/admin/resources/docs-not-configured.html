Documentation isn't configured for this instance

This is a self-hosted ezto Verify deployment and no documentation URL has been set, so there is nowhere to send you. An administrator can point the Docs link at your own documentation.

  1. Set the DOCS_URL environment variable on the IdP to your hosted docs, then restart it: 
    DOCS_URL=https://docs.your-domain.com
  2. Don't host docs yet? The full documentation source ships with the platform under docs/verify (a Docusaurus site). Build and serve it, then point DOCS_URL at the result.

Once DOCS_URL is set, the Docs link opens it directly and this page is no longer shown.
