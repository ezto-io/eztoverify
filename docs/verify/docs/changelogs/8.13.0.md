### New Feature

- We’ve introduced a new [Custom Support](/docs/EV/GetStarted/Branding/CustomSupport) feature, allowing you to set a custom support URL. This ensures users are directed to your preferred help resource, such as a support page, documentation, or contact center, for better assistance.  

- We’ve added a new [helper function](/docs/EV/WorkflowModules/HelperFunctions) called `Split` to several workflow modules, making it easier to configure and use them effectively.

- Added a new key, `regexError`, in [Dynamic Form.](/docs/EV/WorkflowModules/DynamicForm) This key handles regex validation error messages.

### Improvements

- Enhanced the [Brandings](/docs/EV/GetStarted/Branding/Branding/) `form` page by adding more text related color options, providing flexibility in customizing the appearance of the verification page.  
 
- We’ve improved the response codes in the PAN Aadhaar Link Status workflow module to ensure they provide appropriate information. This enhancement improves clarity by making it easier to understand the verification outcome.  

- We customized error handling for Verify PAN, Verify Bank, and Verify Aadhaar with OTP workflow modules. Previously, when execution failed, the entire flow was marked as failed with a generic error message. Now, the flow succeeds, and the specific failure reason for the affected module is included in the response.

### Bug Fixes

- Fixed an issue with [Sub Workflow](/docs/EV/WorkflowModules/SubWorkflow) export. Previously, imported configs appeared broken. Now, the workflow module turns yellow to indicate that it needs proper configuration.

- We fixed an issue in Marketplace installation where, after installing a template with predefined claims, the same set of claims still appeared in the dropdown instead of being updated correctly.
