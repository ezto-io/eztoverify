### Improvements

- We’ve updated the format of claims in the UI to be specific to each workflow module. For example, what was previously formatted as `pan_number` is now displayed as `verify_pan@pan_number`.

- Minor adjustments have been made to improve the overall functionality of the [Dynamic Form](/docs/EV/WorkflowModules/DynamicForm) module.
