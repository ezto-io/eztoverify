### New Features

- Introducing the **OTP-less verification** option in the [Verify Phone](/docs/EV/WorkflowModules/MobileNumber/OTPLess) workflow configs tab! Now, you can easily validate your mobile number against the phone number present in your mobile device without the need for OTPs.

### Bug Fixes

- We've resolved an issue where encryption was not functioning properly in the [Web to Device](/docs/EV/WorkflowModules/Device/WebtoDevice) flow. Now, with added support for encryption in user request payloads, you can trust that your data remains secure throughout the web to device interaction.
