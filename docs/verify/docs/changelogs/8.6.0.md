### Improvements

- We’ve removed the user metadata check from all verification modules. Attributes provided in metadata will no longer undergo internal comparison or validation in any workflows. Instead, these conditions can be validated using the [Validator](/docs/EV/WorkflowModules/Validator) module. Additionally, claims in **ID document-related** workflows have been updated to be specific to each workflow. 

- A **skip** option has been added to workflow modules, allowing workflows to be skipped if not required. However, this option is not supported for device-related workflow modules.

### Bug Fixes

- Resolved few issues in [Dynamic Form](/docs/EV/WorkflowModules/DynamicForm):
  - We fixed an issue where the submit button was not clickable when the **type** was set as `checkbox`.
  - Addressed a UI break caused by lengthy titles by enabling text to wrap to the next line when space is limited.
  - Issue where the **default value** remained editable when the **type** was set as `option` and **editable** was set to `false`. It now functions as expected.

- There was an issue with the combination of [Dynamic Form](/docs/EV/WorkflowModules/DynamicForm) and [Validator](/docs/EV/WorkflowModules/Validator) flow, where the decision-making conditions were not working properly. This has now been fixed.

- Addressed issues in ITR Verification and Verify Form 26AS:  
  - Resolved the problem where results were not displayed for selected custom claims when configured.  
  - Support for selecting the year **2023-2024** in ITR details was missing. This has been fixed, enabling data retrieval for this period.

- For Voter ID with OCR, the missing claims and improper claims have been fixed.

- We fixed a handful of minor bugs.
