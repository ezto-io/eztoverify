### New Feature

- We’ve introduced a new option to customize the end status messages for both the **onboarding** and **verification** workflows. By default, these workflows include predefined titles and messages, but you can now personalize both the title and message at the workflow level and application level.

   - **Workflow Level:** A [**Custom Message**](/verify/docs/EV/WorkflowModules/CustomMessage/) workflow module has been added, allowing you to add a custom logo, title, and description. This message will be displayed when a specific set of workflows are executed.

<GifPlayer name="8.1.0/Custom-message-template"/>

   - **Application Level:** If you want to set a custom message that applies to all workflows executed within a particular application, this can be customized in the application’s **Workflow** tab.

<GifPlayer name="8.1.0/custom_message"/>

### Bugs

- We’ve fixed an issue where, when multiple **Dynamic Form** workflow modules were added to a flow, only the first module completed, causing the others to not execute. Now, all **Dynamic Form** modules will execute and complete properly.

- We fixed an issue where using the same workflow module (e.g., Verify PAN) with different claims caused only the first module’s claims to display. This has now been resolved, and all workflow modules will display their respective claims as expected.
