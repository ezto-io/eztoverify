### Improvements

- We've enhanced the application's configuration with an additional option called **Dead Letter**. This ensures that when a flow is incomplete, the result is still sent to the designated WebHook. By enabling this option, users can retrieve the result of a discontinued flow, allowing them to continue from where they left off.

### Bug Fixes

- An issue where **Fido Register** could not be completed for a second user in the same browser session has been resolved. Previously, the process would stop at a "Fido Try Again" error screen, preventing the second user from completing registration. This has now been fixed.

- We addressed a problem with IVR verification where the flow would fail even when the correct PIN was provided during an IVR call. The issue has been corrected, and the flow will now proceed successfully.
