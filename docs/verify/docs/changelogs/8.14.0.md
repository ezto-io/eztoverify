### Improvements

- We've enhanced the response of several workflow modules by including [error codes.](/docs/EV/WorkflowModules/ErrorCodes) These error codes are now available in the following workflow modules:

   - API Request
   - DigiLocker
   - Name Similarity Check
   - PAN Aadhaar Link Status
   - Selfie Registration
   - Selfie Verification
   - Verify Aadhaar with OTP
   - Verify Bank
   - Verify PAN

- Improved the **Verify Bank** module’s Penny Drop verification process by including an additional claim, `ifsc_code`.
