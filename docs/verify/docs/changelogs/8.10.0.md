### Bug Fixes 

- Resolved an issue in the DigiLocker workflow where fetching only the **Aadhaar** document type unexpectedly retrieved an additional PAN document.

- Fixed a problem with the [Custom Message](/docs/EV/WorkflowModules/CustomMessage) workflow export. Upon import, the logo appeared broken. Now the workflow module turns yellow to show that the workflow module needs to be configured properly.

- A priority issue with [Sub Workflows](/docs/EV/WorkflowModules/SubWorkflow) in flows with a validator. When a workflow has two **Sub Workflow** modules, one on the left and one on the right of the validator having consecutive priorities, we faced an issue with the order of execution. This has now been fixed.

- We addressed a UI issue in the [Secure Message](/docs/EV/WorkflowModules/Device/SecureMessage) workflow module, where exceeding the OTP or text length caused the interface to break. This has been fixed.  

- We fixed multiple issues in the [Terms and Conditions](/docs/EV/WorkflowModules/TermsandConditions) workflow:  
    - Deleting a version previously left input fields related to that version still present. This has been corrected.  
    - When using text as the configuration type, hitting the 1500-character limit triggered an improper error. We've increased the limit to 3000 characters, and exceeding it now displays a proper error message.
