### New Feature 

- We’re excited to introduce the DigiLocker workflow module! This module provides access to digital documents stored in DigiLocker, making it easier to retrieve and securely verify them. It ensures reliable validation while seamlessly connecting to DigiLocker for a smoother experience. 


### Improvements

- In [Selfie Verification](/docs/EV/WorkflowModules/Liveness/SelfieVerification), added an enhancement that allows comparing a selfie taken during the verification process with an image from a previously executed workflow module that supports image claims. This enhancement makes the selfie verification process more efficient and reliable. 

<GifPlayer name="8.8.0/selfie"/>

- Improved our flows to ensure that when onboarding fails, the result is still retrieved with the corresponding status.

### Bug Fixes 

- We resolved an issue in [Web to Device](/docs/EV/WorkflowModules/Device/WebtoDevice) flow where the transaction amount was being deducted twice—once for the web transaction and again for the mobile transaction. 

- Fixed few issues in [Audit:](/docs/EV/Audit/GenerateAuditReport)
  - Corrected a problem where the UI of the Audit report page broke during report generation, and certain audit values were missing in the downloaded file.  
  - Addressed an issue where Audit events for template creation, editing, or deletion were not being logged. These events are now recorded as expected. 

- Fixed few issues in Marketplace:
  - Addressed an issue where unnecessary error messages appeared while creating a **Marketplace** template, disrupting the creation process. 
  - Resolved an issue where random countries were selected in the **Marketplace** dropdown when editing a country name.
