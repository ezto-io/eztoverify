### Improvements 

- We have made an enhancement to the Video KYC workflow module to support an extended verification flow that includes **selfie verification, PAN OCR verification, and face match scoring** between the selfie and PAN OCR image. Then, PAN verification is performed using the extracted PAN details from the OCR image.
