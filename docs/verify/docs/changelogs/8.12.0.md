### New Feature

- We’ve added [Flutter web support](/docs/DeveloperTools/MobileSDK/Flutter/Web) to the ezto verify SDKs. This allows easy integration of verification flows into Flutter web applications.

- We introduced the penny drop feature in the **Verify Bank** workflow module. This feature validates a bank account by making a small transaction to confirm its existence and ownership, ensuring a reliable verification process.

### Improvements

- We made few **API level enhancements** to improve the performance and reliability of the following Workflow Modules:  
  - Verify Aadhaar with OTP
  - Verify PAN
  - Verify Bank
