### Improvements  

- We updated our [WhatsApp](/docs/EV/GetStarted/Configurations/Whatsapp) provider to align with changes made by **Twilio,** our provider. With this update, when using a custom **WhatsApp** provider, you must provide the custom template SIDs in the [Twilio SID workspace attributes.](/docs/EV/GetStarted/Branding/WorkspaceAttributes/TwilioSID)  

- The [Name Similarity Check](/docs/EV/WorkflowModules/IdDocuments/NameSimilarityCheck) workflow module has been improved to match names accurately even if they contain special characters.

- We’ve enhanced the DigiLocker workflow module by adding **Registration of Vehicles** as a new document type for verification. This allows RC details to be fetched for the requested user. Currently, RC retrieval is only available for **Tamil Nadu.**
