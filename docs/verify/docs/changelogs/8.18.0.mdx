### Improvements 

- Made an enhancement to all the toggle button behavior and appearance across the workspace to ensure a consistent user experience.

### Bug Fixes

- Resolved UI inconsistencies across the workspace, including alignment issues in the [FIDO Verification](/docs/EV/WorkflowModules/Fido-passkeys/Verify/) workflow module and “Sorting” options.

- Addressed an issue in the [Web to Device](/docs/EV/WorkflowModules/Device/WebtoDevice/) workflow module, where the proper error message was not displayed when the maximum allowed device count was reached. This is now properly handled.

- Fixed a refresh issue on the consent screen, improving the overall user interaction flow.

- Corrected a configuration issue where **Dead Letter** settings were not properly applied when duplicating applications.

- Resolved responsiveness issues with the download button on the **Audit** page, ensuring it’s properly aligned and functional on smaller screens.

- Fixed an issue where the end message was not displayed at the end of mobile transactions, preventing incomplete feedback for users.
