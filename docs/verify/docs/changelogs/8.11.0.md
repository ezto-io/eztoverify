### New Feature

- **Introducing some handy new Workflow Modules:**
 
  - PAN Aadhaar Link Status: This module checks if an individual's **PAN** and **Aadhaar** are linked. It helps ensure both documents are correctly associated, as required for certain verification processes.

<GifPlayer name="8.11.0/Aadhaar-Pan-link"/>

  - [Name Similarity Check:](/docs/EV/WorkflowModules/IdDocuments/NameSimilarityCheck) This module compares names from two documents and provides a similarity score. It helps spot name differences, making it easier to confirm whether the documents belong to the same person.  

<GifPlayer name="8.11.0/Name-Comparing"/>

### Improvements

- We added a new configuration to the DigiLocker workflow module called `Skip Document Pull from DigiLocker`. This helps avoid fetching documents that aren't available, reducing unnecessary fetch attempts.

- We enhanced the **Web SDK** to support multiple domains. You can now add multiple domains to the configuration, allowing verification across all specified domains instead of just one.
