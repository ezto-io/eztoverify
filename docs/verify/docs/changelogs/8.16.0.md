### Improvements

- We enhanced the [Geo Tagging](/docs/EV/WorkflowModules/GeoTagging) workflow module by adding configuration options to fetch more location-related details, improving accuracy in location retrieval.

<GifPlayer name="8.16.0/Geo-Tagging"/>

- Error Code Enhancements:
  - Added [error codes](/docs/EV/WorkflowModules/ErrorCodes) for Verify Aadhaar with OCR and Driving License with OCR to improve error handling.
  - Updated [error codes](/docs/EV/WorkflowModules/ErrorCodes) for [Selfie Registration](/docs/EV/WorkflowModules/Liveness/SelfieRegistration) and [Selfie Verification](/docs/EV/WorkflowModules/Liveness/SelfieVerification) for better accuracy and consistency.

- We added new claims, `ocr_aadhaar_front_image` and `ocr_aadhaar_back_image`, in **Verify Aadhaar with OCR** to fetch Aadhaar document images extracted through OCR.
 
- [Selfie Registration](/docs/EV/WorkflowModules/Liveness/SelfieRegistration) and [Selfie Verification](/docs/EV/WorkflowModules/Liveness/SelfieVerification) now have an option to enable **Geo Tagging** location fetch in the **Configs** settings.

### Bug Fixes

- We fixed an issue in the **Geo Tagging** workflow module where the page flickered while the flow was executing.

- Resolved a minor issue with importing and exporting the **Custom Message** workflow module.

- Fixed an issue in the **Web to Device** flow where the result was not fetched if the mobile execution was interrupted. Now, results are properly retrieved even when failures occur.
