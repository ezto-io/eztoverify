### Improvements

- Made an enhancement to streamline the input collection. When a [Dynamic Form](/docs/EV/WorkflowModules/DynamicForm) is used to gather inputs, including the **PAN** number, and followed by the Verify PAN workflow, the **PAN number** no longer needs to be re-entered for verification. This enhancement simplifies the process by using the input already collected, improving interaction and reducing redundancy.

### Bug Fixes

- We fixed an issue with [FIDO Verification](/docs/EV/WorkflowModules/Fido-passkeys/Verify) in both the **web SDK** and **desktop applications** where onboarding or verification was not functioning correctly. It now works as expected.  

- Resolved an issue with action variables during export and import. While the import functionality worked as intended, it also fetched unnecessary content. This has been corrected.
