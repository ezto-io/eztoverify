### Bug Fixes 

- In [Web to Device](/docs/EV/WorkflowModules/Device/WebtoDevice), the result would stay stuck in a pending state if the `allow_new_device` field was missing from the request body. We’ve fixed this so that instead of staying in pending or showing an error, it now displays "onboarding/verification failed."

- In **Workspace Attribute**, there was an issue where actions weren’t being recorded in the **Audit** log. We’ve resolved this, and all actions are now properly logged as expected.
