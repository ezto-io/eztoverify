### New Feature  

- We're excited to introduce the [Custom Response](/docs/EV/WorkflowModules/CustomResponse) workflow module. This feature allows us to define and return custom result structures, making it easier to shape outputs based on specific needs.

### Bug Fixes  

- We fixed an issue in the [Custom Message](/docs/EV/WorkflowModules/CustomMessage) workflow where the end message showed the default content instead of the custom message when **Push** was set as the result notification way. The correct custom message now displays as expected.  

- We resolved an issue in [Validator](/docs/EV/WorkflowModules/Validator) where unwanted claims appeared in the response when **Push** was configured as the result notification way.
