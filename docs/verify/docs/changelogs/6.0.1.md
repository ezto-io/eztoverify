# 6.0.1

### Improvements 

- We've enhanced our liveness verification process by integrating face comparison alongside finger count verification. This means that when verifying your identity, not only will we check your unique finger count, but we'll also compare your facial features for added security and accuracy.

- In the user transaction status section, we've introduced color coding to distinguish between different transaction statuses. This makes it easier for users to quickly identify the status of their transactions at a glance.

### Bug Fixes

- We've addressed an issue specifically related to [Azure B2C,](/docs/EV/StartAnIntegration/SetupVerification/AzureB2C) ensuring it now functions smoothly across all web browsers, regardless of cookie settings. If cookies are disabled, users will now receive guidance on enabling them, ensuring uninterrupted access to Azure B2C services.
