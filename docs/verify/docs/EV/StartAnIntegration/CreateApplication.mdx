# Create Application 

Design and customize your application according to your preferences, including the customization of its interface.

With **ezto Verify**, you can establish a verification procedure specific to meet your needs, ensuring secure interactions with users, information, and transactions. Utilize the capabilities of ezto verify to seamlessly integrate and execute verification processes, enhancing both security and user experience.

*1* Navigate to **Workspace**, and click on **Applications.**

*2* Click on the `+ CREATE APPLICATION` button.

*3* You will be taken to the first step, (i.e, **Details)** for creating an application.

### *1* Details

Provide a descriptive name and select the theme that suits best or click on default. Note that, if no themes are created, you can set the **default** theme. To know how to create a **Theme,** see [here](/verify/docs/EV/GetStarted/Branding/Branding/).

### *2* Gatepass

This section allows to set application-level rules that must be met for a transaction to be initiated. Failure to comply with these rules will result in denied user access to initiate the verification flow. To know how these rules work, refer [here](/verify/docs/EV/ControlIntegration/ApplicationLevel/).

![Gatepass](https://images.tango.us/workflows/e4539b39-4152-485c-8361-50a3884e1370/steps/592ec585-1c28-4d81-bd04-d45169fd4300/c0fc9d63-b932-4e06-83fa-dcb98ef778b4.png)

Either configure or skip the step, and click on the `NEXT` button to proceed to the further steps. You can always configure the **Gatepass** rule, even after creating the application.

### *4* Onboarding Workflow

As the fourth step, you will be taken to the **Onboarding Workflow**. During this step, you will need to select which onboarding workflow you want to execute for a newly onboarding user.

Please note that selecting the "None" option for the onboarding workflow will automatically redirect the user to the verification workflow, irrespective of the users availability. To know how to create a workflow, refer [here](/verify/docs/EV/StartAnIntegration/SetupWorkflow/).

![Onboarding Workflow](https://images.tango.us/workflows/e4539b39-4152-485c-8361-50a3884e1370/steps/7211ab13-18ec-4d73-bade-5dfc1d66f205/f137ca96-0e2d-43c1-b786-7a70bad15f61.png)

After selecting the required onboarding workflow or skip,  click on the `NEXT` button to proceed to the further steps.

### *5* Verification Workflow

As the fifth step, you will be taken to **Verification Workflow,** which is required in order to start the verification process. Note that if a user has already been registered/onboarded, they will be taken directly to this verification process. To know how to create a workflow, refer [here](/verify/docs/EV/StartAnIntegration/SetupWorkflow/).

![Verification Workflow](https://images.tango.us/workflows/e4539b39-4152-485c-8361-50a3884e1370/steps/56393d5f-95a4-4a52-9ed8-15d54c5e36fd/2838e54e-49a1-4ba0-a244-b028fc92ab33.png)

After selecting the required verification workflow,  click on the `NEXT` button to proceed to the further steps.

<DropBox title="Know About Custom End Message">

The **Custom Message** feature determines the end message of a workflow through several checks:
 
- First, it checks if a custom message is configured at the **workflow level**. If one is set, that message will be displayed.
 
- If no message is found at the **workflow level,** it moves to the **application level** to see if the custom message option is enabled.
 
- If neither level has a custom message, it checks whether the user is completing the process via **desktop or mobile**, and closes the message check accordingly.
 
- If no custom messages are configured at any level, the **default message** will be displayed.

By default, the end message will be pre-configured. However, if you wish to customize it further, you can do so using below the steps.

After creating your application, you can personalize the final messages displayed to users once they complete either the **Onboarding** or **Verification** workflows. 

- Navigate to **Applications** and select the application you wish to configure.
- Click on the **Workflows** tab.
- For both **Onboarding** and **Verification** workflows, toggle the **Enable End Message** option to add the custom messages.

![Enable](https://images.tango.us/workflows/e4539b39-4152-485c-8361-50a3884e1370/steps/4c1cf1cb-460b-4ac2-a435-72cf965537e1/bf1b8ea6-e0af-4c26-8934-96207a54d7b8.png)

- Once enabled, you can customize the following for both workflows:
   - **Success Message**: Enter a **Title** and a **Description** to display when the workflow completes successfully. For example, a confirmation like "Onboarding/Verification Completed" with a message such as "You can now close the window safely."
   - **Failure Message**: Similarly, provide a **Title** and a **Description** to notify users when the workflow fails. For instance, "Onboarding/Verification Failed" with a description like "No action is required from your side. You can now close the window safely."

![Custom End Message](https://images.tango.us/workflows/e4539b39-4152-485c-8361-50a3884e1370/steps/07303552-3f6f-4847-8d68-c41dadcacdd9/0dbddf8a-909a-45a5-8863-cd8b35bcf704.png?mark-x=172&mark-y=210&m64=aHR0cHM6Ly9pbWFnZXMudGFuZ28udXMvc3RhdGljL2JsYW5rLnBuZz9tYXNrPWNvcm5lcnMmYm9yZGVyPTQlMkNEQjMwMzAmdz02MjgmaD0yODYmZml0PWNyb3AmY29ybmVyLXJhZGl1cz0xMA%3D%3D)

- Once you add your required contents, ensure to save your changes.

To customize the end message at the workflow level, please refer to this [guide.](/docs/EV/WorkflowModules/CustomMessage)

These customizable messages allow you to guide users through the final stages of the onboarding and verification processes, ensuring they understand the outcome and what to do next.
</DropBox>
