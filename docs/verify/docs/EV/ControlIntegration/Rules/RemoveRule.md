This action involves removing or deleting a specific set of outdated, unnecessary, or incorrect rules.

Here's how to remove rules that are currently unnecessary,

*1* Navigate to **Workspace**, and click on **Rules.**

*2* You will be presented with a list of existing (created) rules.

![Rules List](https://images.tango.us/workflows/77024e12-4a5d-41ff-b4be-06c99f60c4c4/steps/141b87ec-c817-46f6-81f2-922235a44692/a12c1d32-5c00-4c79-aa1a-9b8d329ce0d3.png)

> Note that, If you wish to make changes to the flow instead of deleting it, you can find the edit icon located alongside the rule's name.

*3* Click on the name of the rule you want to delete, make sure it contains the rule you wish to remove.

*4* You will be directed to the rule's configs page.

*5* The **Delete** option will be displayed on the top right, click on the `DELETE` button**.**

![Remove Rule](https://images.tango.us/workflows/77024e12-4a5d-41ff-b4be-06c99f60c4c4/steps/71c320d1-b3f7-4ac6-a719-25e10ec143a5/1dd163e1-3f1a-44ae-9131-97e30e2745c9.png)

*6* You will be prompted with a confirmation pop-up, click on `DELETE` to remove.
