Create a consistently branded experience for your users by styling your verification prompts with **ezto verify's** no-code editor. It allows you to easily customize the colors, texts, fonts, borders, and backgrounds of the prompts displayed throughout the verification flow. 


With the no-code editor, you can effortlessly customize your verification branding theme to match your brand's unique identity.

## Custom Branding Implementation

*1* Navigate to you **Workspace** and click on **Brandings**

*2* Click on `+ CREATE BRANDING`

*3* Provide a descriptive name and click on **CREATE**.

*4* Select a theme component (e.g., Layout) from the right-side menu and customize the available options.

*5* After customizing your theme, click on **Publish**.

Once you've published your theme, you can access a live preview of your verification experience to review and test your screens. To do this, you need to attach the branding to an application. To know how to, see here.

:::note
To revert to the default settings and undo any changes you've made, simply click on the **RESET** button. This action will restore the original configuration, allowing you to start fresh or go back to the previous state.
:::

<DropBox title="Form">

This allows you to customize the form to your preferences by modifying various aspects such as border colors, button color, text color, logo positioning, and more. This ensures that the form aligns perfectly with your branding and design requirements, providing a cohesive user experience.

| Elements | Descriptions |
|----------|--------------|
| TextBox Border Color | Use this field to modify the color of the border surrounding the text box.|
| TextBox Active Color| Use this field to set the color of the text box when it is focused.|
| Text Box Background Color | Choose the background color of the text box. |
| Text Box Text Color | Set the text color inside the text box.|
| Form Text Color | Configure the color of the text within the form.|
| Form Background Color | You can choose the background color for the form.|
| Form Border Color | Utilize this field to modify the color of the form's border.|
| Form Border Width| Set the width of the form's border using this field.|
| Form Border Radius|  Adjust the border radius of the form using this field.|
| Button Background Color|  You can choose the background color for the button.|
| Button Border Radius| Adjust the button's border radius using this field.|
| Button Text Color| Set the text color of the button here.|
| Logo Position| You can configure the alignment of the logo, choosing from options such as **Left, Right, or Center.**|
| Logo Height| Use this field to specify the size of the logo.|
| Custom Logo Position| Utilize this field to establish a personalized position for the logo within the form.|

<DropBox title="Attach Brandings to Application">

To observe the custom brandings in action, simply select the branding you've established within your application and execute the process.

*1* Navigate to **Workspace**, and click on **Applications**.

*2* Choose the application to which you want to attach the branding. To know how to create an application, refer [here](/verify/docs/EV/StartAnIntegration/CreateApplication/).

*3* You will be directed to its **General** tab. From this section, find the **Theme** field, and choose your custom branding from the drop-down.
